How to read this page. REFERENCE = an existing project image (pipeline concept input or a render of our own model), hosted because it's project-made. IN-GAME MODEL = our treatment: the shipped model re-staged at Lagos dusk (warm key light, cool rim, asphalt, soft shadows) in a three.js stage. Same mesh and texture as the build. CONCEPT = a new design proposal, not in the game yet. No real people are depicted: every human is one of our own generated in-game models. Provenance is listed in each reference/*/README.md.
