# Gidi++ Unity export (Home, Base Camp Shop, Game Over, in-run HUD)

Generated by `tools/gen_unity.py` (re-run it after design changes). Machine-readable list: `manifest.json`.
Layout source of truth: `../hud/HUD_Landscape_Spec.md` (in-run HUD, OWA! rule, tablet two-row) and the screen mockups in `../../mockups/` (`home-*`, `shop-*`, `gameover-*`, `hud-*`).

**Counts:** 112 sprites × 2 scales (224 PNGs), 16 backgrounds (8 graded + 8 blurred), 18 of the sprites are 9-slice, 34 icon SVGs + logo SVGs in `svg/`.

## Unity import settings
| Setting | Value |
|---|---|
| Texture Type | **Sprite (2D and UI)**, Sprite Mode Single |
| Pixels Per Unit | **100** for @1x; **200** for @2x (so both have the same size in UI units). Canvas: Scale With Screen Size 1920×1080, match height 1.0 |
| Mesh Type | **Full Rect** (required for 9-slice; fine for everything) |
| Sprite borders | from the 9-slice table / `manifest.json` (@1x px; double for @2x) |
| Filter Mode | **Bilinear**; Wrap Mode Clamp; Generate Mip Maps **off** |
| Compression | **None** for UI sprites (soft alpha glass and glows band badly). If memory matters: put sprites in a Sprite Atlas, ASTC 4×4 (mobile) / BC7 (desktop) on the atlas; backgrounds may use ASTC 6×6 / DXT5 |
| Alpha | Alpha Is Transparency on; sRGB on |
| Max size | 2048 (sprites), 2048 or 4096 for backgrounds |
| Which scale | Ship @2x on phones/tablets (≥ 2x DPI) and @1x on WebGL/desktop, or @2x only and let the atlas downscale |

Use `Image.type = Sliced` for 9-slice sprites (Fill Center on). Text is never baked into buttons: use TextMeshPro with Plus Jakarta Sans Bold.

Z-order (back → front): background → world telegraphs → HUD glass panels → touch controls (PICK UP, OWA!, d-pad; never overlapping) → toasts → modals (with a dim layer `#02030A` at 62% for Game Over, 55% for Pause).

### OWA! layer stack (code-driven)
`owa_glow` (only when highlighted) → `owa_disc` → `owa_outline` → label (TMP "OWA!", 28 px, `#E8B21E`) → pip row of 3. Each pip = `pip_empty` → `pip_partial_ring` + `pip_partial_fill` (Image Filled, Radial 360, origin Top, clockwise, `fillAmount` = refill progress) for the charging pip → `pip_filled` for ready charges. At 0 charges and no refill swap disc+outline for `owa_disabled`, label colour `rgba(200,200,200,.6)`. Pressed: `owa_pressed` overlay.
